# Security

The current main branch is maintained; older snapshots have no separate security support. Report exploitable vulnerabilities privately through this repository's **Security → Report a vulnerability** feature. Do not post secrets or personal saves in public issues. Expect an initial response when the volunteer maintainer is available; there is no guaranteed response SLA.

This is a static client-side game with browser-local saves. It has no accounts, payments, server authority or anti-cheat guarantees. Import/export is for personal saves, not a trusted competitive format. Ordinary gameplay bugs belong in Issues.
